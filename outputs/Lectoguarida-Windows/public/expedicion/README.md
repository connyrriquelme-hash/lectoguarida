# Expedición

Este subdirectorio está pensado para publicarse como `lectoguarida.cl/expedicion`.

Estructura:

- `index.html`: pasarela de acceso con dos tarjetas.
- `auth.js`: validación frontend simulada y redirecciones internas.
- `juego.html`: contenedor base para el juego.
- `dashboard.html`: panel docente estático de inicio.
- `assets/`: imágenes y audios del proyecto.

No modifica el sitio principal `lectoguarida.cl`.
